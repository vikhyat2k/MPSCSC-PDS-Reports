  2. APIs & Services > Library में जाकर Gmail API खोजें और Enable करें।
  3. APIs & Services > Credentials में जाएं और Create Credentials > OAuth client ID चुनें।
  4. Application type में Web application चुनें।
  5. Authorized redirect URIs में ऊपर दिया गया Redirect URI जोड़ें: http://localhost:3000/api/gmail/oauth/callback.
  6. प्राप्त Client ID और Client Secret को ऊपर दिए गए बॉक्स में पेस्ट करके सुरक्षित करें पर क्लिक करें।
